# Requirement Document- Leads Enhancement (Sales CRM)
## Executive Summary
This document describes the need for Leads module Enhancement. The enhancement implies, adding two view to the Leads module listing view.
## Prerequisites
The two new views required are-
1) Table View
2) Broad View
## Modules effecting
Module Name | Module Type
---- |----
Leads | Leads, Lead contact
## Change Type
We are enhancing the feature by adding two new views-
1) Table View
2) Broad View
## Current Scope and Function
* As per our current functionality we don’t have a Deal module. Need to implement it.
* Also we need to Add two views on the leads module listing view-
   1. Table View  2. Board View
* Users need to have the option to switch between Table view (Regular View) and Board View.
* We already have a macro option for client contacts; the same thing will be implemented for lead contacts.
* In the custom labels of the business units, we already have a Show/Hide field option for all modules. The same functionality must be implemented for the leads module.
* We already have a Reorder fields option for all the modules; the same thing will be implemented for Leads and Lead contacts.
* We already have the tag option in the applicant module where users can insert tags for each applicant and see.
## New Scope and Function
### Create New Deal Option:
* Once the user clicks on Create Deals from the Deals table or board view:
* Deal Name: To enter the Deal name
* Deal Owner:  Show the logged-in user as the Deal owner
* Stage: Give a drop-down option to select the configured Deal stages on the setup
* Closing Date: Give a Date picker
* Deal Type: Give a drop-down option to select the configured Deal types on the setup
* Deal Source: Give a drop-down option to select the configured Deal Sources on the setup
* Lead company: Give a search option to search the available lead records
* Primary Contact: Show the available associated lead contacts upon selecting the lead company?
* Lead Contact: Show the available lead contacts
* Amount/Target Placements: Give two radio buttons Amount & Total Placements
* If the user Selects the Amount give a free text option to enter the amount with the currency selection. If the user selects the Total Placements show a placeholder to enter the numeric value 
* Next Step: Give a free text placeholder for entering the next step ?
* Deal Description: Give a place to enter the Deal information and description
## Affected Areas
The new feature will only affect the Leads module.
## Benefits
It will benefit the users in managing Leads and Deals.
